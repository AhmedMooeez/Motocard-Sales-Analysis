# 🏍️ Motocard – Sales Data Analysis & Dashboard

## 📌 Project Overview

An end-to-end sales data analysis project for Motocard, a Spanish retailer specializing in motorcycle gear and apparel.

This project focuses on analyzing sales performance, customer demographics, product categories, and profitability to generate meaningful business insights through an interactive Excel dashboard.

## 🎯 Key Performance Indicators (KPIs)

- Total Orders
- Average Customer Age
- Total Cost
- Total Revenue
- Gross Profit
- Profit Margin

## 📊 Key Analysis

- Yearly Sales Performance
- Sales Distribution by Gender
- Sales Analysis by Product Category
- Top 5 Most Profitable Products

## 🛠️ Tools & Techniques

- Microsoft Excel
- Pivot Tables
- Data Analysis
- Data Visualization
- Interactive Dashboard Design
